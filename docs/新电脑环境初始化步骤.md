# AI Portal 新电脑环境初始化步骤

这份步骤用于新电脑，不依赖当前电脑已经安装的 Python、Node.js 或 Git 版本。

## 1. 安装统一工具

按项目版本安装：

| 工具 | 版本 |
| --- | --- |
| Python | 3.13.15，安装时勾选 Add Python to PATH |
| Node.js | v24.21.0，使用官方 LTS 安装包 |
| Git for Windows | 安装包 2.55.0.5；命令行版本 2.55.0 或更高 |
| Docker Desktop | 当前稳定版，启用 WSL2 后端和 Docker Compose V2 |
| PyCharm | 使用支持 Python 3.13 的版本 |

Git for Windows 安装包可以显示为 `2.55.0.5`，命令行通常显示为 `git version 2.55.0.windows.1`；脚本只校验命令行可识别的前三段版本号不低于 2.55.0。

## 2. 获取项目

```powershell
git clone <公司 Git 仓库地址> ai-portal
cd ai-portal
```

不要从其他电脑复制 `backend/.venv`、`frontend/node_modules`、`frontend/dist` 或 `.data`。

## 3. 验证版本

```powershell
python --version
node --version
npm --version
git --version
.\scripts\verify-environment.ps1 -SkipDocker
```

预期结果：Python 3.13.15、Node v24.21.0、npm 11.x、Git 2.55.0 或更高版本。脚本失败时先修正版本，不要修改脚本绕过检查。

## 4. 创建本机开发环境

```powershell
Copy-Item infra/.env.example infra/.env

cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -e .

cd ..\frontend
npm install
```

每台电脑可以使用自己的 `infra/.env`，但变量名称、Compose 文件、镜像版本和端口约定必须保持一致。密码和 API Key 不提交 Git。

## 5. 启动与检查

```powershell
cd ..
docker compose --env-file infra/.env -f infra/docker-compose.yml up -d

cd backend
.\.venv\Scripts\Activate.ps1
uvicorn app.main:app --reload --port 8000
```

另开终端启动前端：

```powershell
cd frontend
npm run dev
```

访问 `http://localhost:5173`，后端健康检查为 `http://localhost:8000/health`。
