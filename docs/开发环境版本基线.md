# AI Portal 开发环境版本基线

本项目四台开发电脑和 CI 环境统一使用以下版本：

| 工具 | 版本要求 | 统一位置/校验方式 |
| --- | --- | --- |
| Python | 3.13.15 | 根目录 `.python-version`；`scripts/verify-environment.ps1` |
| Node.js | 24.21.0 | 根目录 `.node-version`；`frontend/package.json` engines |
| npm | 11.x | `frontend/package.json` engines；随 Node.js 24.21.0 提供的 npm 使用 |
| Git for Windows | 安装包 2.55.0.5；命令行版本 2.55.0 或更高 | `scripts/verify-environment.ps1`；命令行通常显示 `2.55.0.windows.1` |
| Docker Compose | V2 | `docker compose version`；使用 `infra/docker-compose.yml` |

容器运行时也使用同一基线：后端镜像为 `python:3.13.15-slim-bookworm`，前端构建镜像为 `node:24.21.0-alpine`。这样开发机、CI 和云服务器的 Python/Node 主版本保持一致，避免本地能运行、容器无法构建的情况。

## 检查命令

```powershell
python --version
node --version
npm --version
git --version
.\scripts\verify-environment.ps1 -SkipDocker
```

新电脑首次配置时，先安装以上版本，再创建新的 `backend/.venv` 并执行 `npm install`；不要复制其他电脑的 `.venv`、`node_modules` 或 `.data` 目录。
